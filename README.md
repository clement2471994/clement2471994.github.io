# Clement Lab

Personal lab site, live at **https://clement2471994.github.io**.

- Plain static HTML and CSS, hosted on GitHub Pages. No build step.
- Push to `main` to deploy.
- Local preview: `python3 -m http.server 8000`.

## Working with AI agents

This repo is set up for agentic coding tools:

- `AGENTS.md` is the single source of instructions for any agent.
- `CLAUDE.md` and `.cursor/rules/project.mdc` point back to `AGENTS.md`.
- `.agents/skills/*/SKILL.md` are step-by-step playbooks for common tasks.
